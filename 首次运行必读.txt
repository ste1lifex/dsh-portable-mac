DSH · macOS 安装与升级必读
============================

这份文件是写给「第一次用 Mac 命令行」的人的，每一步都写清楚了。
遇到问题先跳到第四节「常见问题」。


--------------------------------------------------------------------
一、装之前，先确认两件事
--------------------------------------------------------------------

1) 你的 Mac 是不是 Apple 芯片（M1 / M2 / M3 / M4）？

   点屏幕左上角的苹果图标 →「关于本机」，看「芯片」那一行：
     · 写着 Apple M1 / M2 / M3 / M4 …  → 可以用这个包
     · 写着 Intel Core i5 / i7 …       → 不能用（本包只做了 Apple 芯片版）
   「关于本机」里的「macOS 版本」需要是 11 或更高。

2) 你以前是不是装过 DSH？

   装过 → 请先看第二节「升级」，否则新版会「双击没反应」。
   从没装过 → 直接看第三节「第一次安装」。


--------------------------------------------------------------------
二、升级：已经装过旧版 DSH（★ 最重要的一节）
--------------------------------------------------------------------

为什么要先退出旧版？

   两份 DSH 共用同一个数据目录，系统同一时间只允许一个 DSH 在运行。
   旧版还在跑的时候，你去双击新版 DSH.app 会「什么都不发生」——
   不弹窗、不报错、图标跳一下就没了。因为它一启动就发现
   「已经有一个 DSH 在跑了」，于是自己悄悄退出了。

   所以你看到「双击没反应」，不是包坏了，是旧版还没退。

怎么退出正在运行的 DSH（任选一种）：

   · 点一下 DSH 窗口，按键盘 Command + Q
   · 或：屏幕最上方菜单栏点「DSH」→ 下拉里点「退出 DSH」
   · 或：右键点 Dock（屏幕底部）里的 DSH 图标 →「退出」
   · 或：按 Command + 空格，输入「活动监视器」回车，
         在搜索框里输入 DSH，选中列表里的 DSH，
         点窗口左上角的「✕」→「强制退出」

怎么确认真的退干净了：

   · Dock 里已经没有 DSH 图标了；
   · 再打开「活动监视器」搜 DSH，列表是空的。

退干净之后，再按第三节打开新版就行。你的历史会话不会丢
（新旧版共用同一个数据目录）。


--------------------------------------------------------------------
三、第一次安装（一步一步照做）
--------------------------------------------------------------------

第 1 步 · 解压

   打开「访达」（Dock 最左边那个笑脸图标）→ 左边点「下载」，
   找到 DSH-portable-0.1.5-rc.2-mac-arm64.zip，双击它。

   macOS 会自动解压出一个文件夹，里面有：
     · DSH.app          ← 主角，就是要装的应用
     · 安装.command     ← 安装助手（第 3 步要用）
     · 使用说明.md / 首次运行必读.txt（就是本文件）

   双击 zip 没反应、或者解压不出来？
   右键点这个 zip →「打开方式」→「归档实用工具」。


第 2 步 · 打开「终端」

   终端就是一个可以打字下命令的窗口，不用怕，下面会让你复制粘贴。
   三种打开方式，任选一种：

     方法 A（最快）：按 Command + 空格，输入「终端」两个字，回车。
     方法 B：点 Dock 里的「启动台」→ 打开「其他」文件夹 → 点「终端」。
     方法 C：访达 → 左边点「应用程序」→「实用工具」→ 双击「终端」。


第 3 步 · 在终端里运行安装助手

   ★ 不要手打路径，一定会打错。用「拖拽」的方式：

     1) 在终端窗口里先输入这 5 个字符（bash 后面有一个空格）：
            bash

     2) 把解压出来的文件夹里的「安装.command」直接拖进终端窗口，
        路径会自动填上去。

     3) 按回车。

   终端会显示（大致如下）：

      ==============================================
        DSH 安装助手（macOS / Apple Silicon）
      ==============================================
      [1/4] 解除下载隔离标记…
            完成
      [2/4] 修复可执行权限…
            完成
      [3/4] 校验签名（ad-hoc，无需开发者账号）…
            ✅ 包内签名有效 —— 本包在 macOS 上构建时已签名，无需重新签名
      [4/4] 安装位置
            把 DSH.app 复制到「应用程序」文件夹？[Y/n]

   直接按回车（等于选 Y）→ 它会装进「应用程序」并自动打开。
   不想装到「应用程序」就输入 n 再回车。

   ▶ 如果它让你输入密码：
     那是「复制到应用程序文件夹」需要管理员权限。
     输入你开机的登录密码，然后回车。
     注意：打字的时候屏幕上不会显示任何字符（连小圆点都没有），
     这是正常的，照打就行。


第 4 步 · 等它自己准备（第一次大约 1-2 分钟）

   首次启动会把包内自带的离线依赖缓存展开，全程不需要联网。
   窗口顶部那条控制条会显示「首次运行：正在展开…」，
   等它变成正常界面就好了。以后每次启动都是秒开。


第 5 步 · 填 API Key（想真正对话才需要）

   1) 访达里按 Command + Shift + G，粘贴下面这行，回车：
          ~/Library/Application Support/DSH/app-npm

   2) 在打开的文件夹里找到 .env 文件，右键 →「打开方式」→「文本编辑」。

   3) 找到这一行：      DEEPSEEK_API_KEY=
      改成：            DEEPSEEK_API_KEY=sk-你的密钥
      （密钥在 https://platform.deepseek.com 申请）

   4) 保存（Command + S），关掉文本编辑，然后重启 DSH。

   小技巧：不想找文件夹，也可以在 DSH 窗口顶部的菜单栏点
   「DSH」→「打开数据目录」，直接就打开了。


--------------------------------------------------------------------
四、常见问题
--------------------------------------------------------------------

Q1. 双击 DSH.app 完全没反应，不弹窗也不报错？

   → 99% 是「已经有一个 DSH 在跑」。这就是第二节讲的情况：
     新旧两份共用同一个数据目录，后启动的那个会静默退出。
     解决：按第二节把旧的那份彻底退出，再打开新的。
     如果确认已退出还是没反应，打开「活动监视器」搜 DSH，
     全部强制退出后再试。

Q2. 提示「Apple 无法验证开发者」/「无法打开，因为无法验证开发者」？

   → 这个 App 没有买 Apple 的开发者签名（99 美元/年），属于「未公证」，
     不是包坏了。两种放行办法：
       · 右键点 DSH.app →「打开」→ 在弹出的框里再点「打开」；
       · 或「系统设置」→「隐私与安全性」→ 拉到最下面 → 点「仍要打开」。

Q3. 提示「DSH.app 已损坏，无法打开」？

   → 正常发行包不会出现这一条（本包在 macOS 上构建时就签好名了）。
     真出现了说明签名被改坏了（例如你自己动过包里的文件），
     按第三节第 3 步重跑一次安装助手即可。

Q4. 双击 安装.command 没反应 / 提示权限不足？

   → 系统会拦这种脚本文件。改用第三节第 2、3 步：
     打开「终端」，用 bash 把它跑起来。

Q5. 终端里提示 command not found？

   → 确认你输的是「bash」后面跟一个空格，再把 安装.command 拖进去。
     拖拽会自动带上正确的路径和引号。

Q6. 界面一直卡在「正在准备…」？

   → 点顶部控制条的「版本信息」按钮，里面有「错误日志」可以看；
     日志文件在：
       ~/Library/Application Support/DSH/logs/dsh-web.out.log
     （菜单栏「DSH」→「打开日志目录」可以直接打开这个文件夹。）


--------------------------------------------------------------------
五、你的数据放在哪 / 怎么备份
--------------------------------------------------------------------

   ~/Library/Application Support/DSH/dsh-home/

   里面有会话记录、设置、凭证、插件配置。备份就备份这一个文件夹。
   访达里按 Command + Shift + G，粘贴上面那行路径即可直达。

   注意：升级或重装 App 都不会动这里，所以历史会话不会丢。


--------------------------------------------------------------------
六、完全卸载
--------------------------------------------------------------------

   1. 按 Command + Q 退出 DSH；
   2. 把「应用程序」里的 DSH.app 拖进废纸篓；
   3. 想连数据一起删干净：访达按 Command + Shift + G，粘贴
         ~/Library/Application Support/DSH
      把整个 DSH 文件夹拖进废纸篓。


--------------------------------------------------------------------
七、给开发者
--------------------------------------------------------------------

   想从源码构建一个「构建时就签好名、且带离线缓存」的包：

     bash tools/build-offline-store.sh     # 生成并自检离线依赖缓存
     bash tools/build-app-mac.sh           # 组装 + ad-hoc 签名 + 打包

   详见仓库 tools/README-mac.md。
